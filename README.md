# Markov Chain Based Stock Market Analysis

A Python project that models stock market movement using a Markov Chain.

## Objective
To analyze long-term stock market behavior using three market states:
- Up
- Down
- Stable

## Features
- Created a transition probability matrix
- Calculated steady-state probabilities
- Used eigenvalues and eigenvectors for analysis
- Visualized market-state probabilities using graphs

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Output
The graph shows the long-term probability distribution of Up, Down, and Stable market conditions.
